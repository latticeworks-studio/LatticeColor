# Keyboard Shortcuts

## Global Hotkey

Works from any app, even when LatticeColor is hidden.

| Shortcut | Action |
|---|---|
| `Ctrl + Shift + C` | Activate the eyedropper |

---

## Eyedropper Overlay

These shortcuts work while the fullscreen colour-picker overlay is open.

| Shortcut | Action |
|---|---|
| `Escape` | Cancel — close the overlay without picking a colour |
| `Click` | Pick the colour under the cursor and return to the panel |

---

## Colour Picker Popover

These shortcuts work while the HSV colour picker is open (click the main swatch to open it).

| Shortcut | Action |
|---|---|
| `Escape` | Close the colour picker |
| `Enter` (in hex field) | Apply the typed hex value |

---

## System Tray

| Action | Result |
|---|---|
| Left-click tray icon | Show / hide the panel |
| Right-click tray icon | Open tray menu (Show / Hide, Quit) |
