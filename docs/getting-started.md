# Getting Started

## Installation

Download the latest `.msi` installer from the [Releases](https://github.com/latticeworks-studio/LatticeColor/releases) page and run it. Windows may show a SmartScreen prompt — click **More info → Run anyway**.

LatticeColor installs to your user directory and starts a tray icon on launch.

## Summon the Window

LatticeColor lives in your system tray. Show or hide it three ways:

- **`Ctrl + Shift + C`** — global hotkey, activates the eyedropper from any app
- **Left-click** the tray icon — toggles the panel
- **Right-click** the tray icon → **Show / Hide**

The panel is always-on-top by design so it stays accessible while you work.

Closing the window with the **×** button hides it to tray. To fully quit, right-click the tray icon → **Quit LatticeColor**.

## Picking Your First Color

1. Press `Ctrl + Shift + C` (or click the eyedropper button in the title bar).
2. Your screen freezes into a fullscreen overlay. Move your cursor over the color you want — a magnifier shows a zoomed pixel grid under the cursor.
3. Click to pick. The panel reappears with the selected color loaded.

The picked color is immediately available in all formats: Hex, RGB, HSL, and OKLCH.

## Window Position

LatticeColor remembers where you leave it. Drag the panel anywhere — it will reopen in the same spot after a restart.
